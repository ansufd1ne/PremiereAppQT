# PremiereAppQt

Première application Qt versionnée avec Git (TP guidé, BTS CIEL option IR).

## Contenu

- `MiniTP` : application Qt Widgets (qmake, Qt 5.14.2, MinGW 64).
  - Un bouton « Ajouter 1 » et un compteur.
  - Un `QTimer` qui incrémente le compteur chaque seconde.
  - Un contrôleur simulé qui envoie une trame `X:Y` toutes les 200 ms, un journal et un bouton ARRET.

## Compilation

Ouvrir `MiniTP/MiniTP.pro` dans Qt Creator, choisir le kit Desktop Qt 5.14.2 MinGW 64-bit, puis lancer la compilation.
